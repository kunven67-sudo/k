02 Chrome extension STRICT SITES

  1. Unzip edit-website-extension.zip
  2. Open chrome://extensions
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and pick the edit-website-extension folder.
  5. Pin it from the puzzle icon. Click it, or press Alt+Shift+E on any site.

Works on every site, even the super strict ones, and your changes come back by themselves when you open the page again.

Extra (in the extension's Details): turn on Allow User Scripts so your own JavaScript runs everywhere, and Allow access to file URLs to edit .html files on your PC.

What's inside

The editor floats on top of the website. Drag it by the top bar, resize it from the bottom-left corner, shrink it to a little button.

PICKPoint at anything and click it. Edit the words, delete it, copy it, move it, resize it, recolor it, swap its picture, change its font, make it glow.
CODEThe page's code as a tree like Inspect. Click a line to find it on the page, type in the code box and the page changes as you type. Search by words, tags, classes.
BACKGROUNDColors, gradients, your own picture, GIF or video, or 12 animated ones: warp stars, Matrix, galaxy, fire, synthwave... plus darken and blur so text stays readable.
EFFECTSGravity (throw stuff around), snow, rain, confetti, rainbow, night vision, upside down, earthquake, dance party with music, Comic Sans everything, click fireworks and more.
ADDYour own text, buttons, pictures, videos, popups, sticky notes, links, shapes, news tickers. Replace every word or every picture on the page.
DO STUFFMake anything do something when clicked: popup, sound, say words out loud, explode confetti, shake the page, change the background, hide things, run away from the mouse.
CSS / JSWrite your own styles (they apply as you type) and your own JavaScript with a Run button and output, plus examples to start from.
SAVEAuto-saves everything. Undo/redo, a history you can jump back in, backups, and Download edited site as one .html file that still works offline.
