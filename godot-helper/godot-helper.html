Godot in 5 minutes

Everything in Godot is made from 4 ideas. Get these and the rest clicks.

1. Nodes = LEGO pieces

Every piece does ONE job. A Camera3D is your eyes. A MeshInstance3D is something you can see. A CollisionShape3D makes it solid. An AudioStreamPlayer plays a sound.

2. Scenes = stuff built from pieces

Snap nodes together and save them, and that's a scene. Your player is a scene. A zombie is a scene. A level is a scene. You can drop scenes inside other scenes, like putting 20 zombies in a level.

3. Scripts = the brain

A script is code stuck on a node that tells it what to do: "move when I press W", "chase the player", "lose health when shot". Godot's code language is GDScript, and it reads almost like English.

4. Signals = messages

Nodes send messages when stuff happens. A button sends pressed. A zombie can send died. Other nodes listen and react, like the score going up when a zombie dies.

What a zombie game looks like inside

Level Node3D # the whole map ├─ Sun DirectionalLight3D # light, or it's pitch black ├─ Sky WorldEnvironment # sky color, fog ├─ Floor StaticBody3D # solid ground ├─ Player player.tscn # you ├─ ZombieSpawner spawner.tscn # makes zombies in waves └─ HUD hud.tscn # health + ammo on screen
The trick: build every thing as its own scene (player, zombie, gun), test it, then drop it into the level. If something breaks, you know exactly which piece it is.

GDScript in 60 seconds


  
  
Spaces matter. GDScript uses indentation (the space at the start of a line) to know what's inside what. Everything inside a func must be pushed in by one Tab. Most beginner errors are a wrong Tab.







  
The editor

  
What every panel is for. Godot looks scary but there are only 5 parts.

  

    
PanelWhereWhat it does

    
Scenetop leftThe list of nodes in the scene you have open. Click + to add a node. Drag nodes onto each other to make them children.

    
FileSystembottom leftAll your files: scenes (.tscn), scripts (.gd), models, sounds. Drag a model or scene from here into the 3D view to place it.

    
ViewportmiddleThe 3D view where you build. The tabs on top switch between 2D, 3D, Script and AssetLib.

    
InspectorrightAll the settings of the node you clicked: size, color, speed, health. Anything with @export in your script shows up here.

    
OutputbottomWhere print() text and errors show. When something breaks, look here first. Red = error, yellow = warning.

Starting a new 3D game

  
    
    
  1. Open Godot and click Create. Name it, pick a folder, and keep the renderer on Forward+. If your PC lags, switch to Mobile, which is lighter.
    2. 
    
  2. In the Scene panel, click 3D Scene. That makes a Node3D, the root of your level.
    3. 
    
  3. Press Ctrl+S and save it as level_1.tscn.
    4. 
    
  4. Click the 3 dots at the top of the 3D view and pick Add Sun to Scene and Add Environment to Scene. That's free light and sky.
    5. 
    
  5. Press F6 to play the scene you have open.
    6. 
  

  
Getting real 3D models: kenney.nl and quaternius.com have tons of free ones, zombies included. Download the .glb version and drag it into your FileSystem panel.

How to paste code right: make the script, press Ctrl+A to select everything Godot put in there, delete it, THEN paste. If you paste under Godot's example code, the Tabs mix up and you get errors.
