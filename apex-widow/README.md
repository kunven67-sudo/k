# APEX WIDOW

Third-person 3D game: a black widow lab spider that escapes VOSS Biogenetics
and grows from 2mm up the size ladder. Single self-contained HTML file
(three.js bundled in), PC + mouse. Build: `node tools/build.mjs` -> dist/apex-widow.html

First playable: injection cutscene + breakout, the VOSS lab (hunt bugs, eat,
web-zip, wrap prey, grow, molt + pick an evolution), real 8-leg IK walk with
wall/ceiling climbing, then burst out the window into night-time New Halvern.
