Wildfowl is an original, fan-made homage to backyard hunting-gallery games, built entirely from scratch with Three.js.

Design, code, low-poly art and sound: all generated procedurally for this project - no external art, texture or audio files anywhere.

Every duck, every wall, every honk and bang you hear was built at runtime out of primitives, canvas textures and oscillators.

Made with a cardboard shotgun, a very opinionated dog, and a healthy respect for the trope.
